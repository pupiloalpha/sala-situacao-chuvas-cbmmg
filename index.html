Impressão / PDF visual
Como gerar o PDF com os painéis oficiais
  1. Aguarde os painéis abaixo carregarem (use “Recarregar” se necessário).
  2. Clique em 🖨️ Imprimir / Salvar como PDF.
  3. Na janela de impressão: escolha “Salvar como PDF”, orientação Retrato, e ative “Gráficos de segundo plano” (Chrome/Edge) para manter as cores.
  4. Cada painel tenta ocupar uma página A4. Painéis que bloqueiam iframe aparecem em branco — use o link “Abrir em nova aba”.
